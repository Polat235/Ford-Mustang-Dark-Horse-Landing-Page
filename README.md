The dark side of performance: A modern, fully responsive, and high-performance showcase website custom-built for the **2025 Ford Mustang Dark Horse**.

---

## 🌟 Key Features

- 🎨 **Modern & Aggressive Design:** Dark-themed UI highlighted with signature gold accents (`#f5c518`) tailored to the Dark Horse identity.
- 📱 **Fully Responsive Layout:** Flawless user experience across desktop, tablet, and mobile devices.
- ⚡ **Smooth Animations:** CSS `@keyframes` animations and subtle background zoom effects in the hero section.
- 📋 **Interactive Test Drive Form:** User-friendly reservation interface complete with form validation and success feedback state.
- 🛠️ **Clean & Compliant Codebase:** 
  - Strict adherence to W3C HTML5 and CSS3 standards.
  - Cross-browser compatibility (including `-webkit-backdrop-filter` support for Safari/iOS).
  - Zero linter/validator warnings (fully eliminated inline CSS and character encoding issues).

---

## 🛠️ Tech Stack

- **HTML5:** Semantic markup structure prioritizing accessibility and clean hierarchy.
- **CSS3:** Custom properties (variables), Flexbox, CSS Grid, Backdrop-Filter, and custom animation keyframes.
- **JavaScript (ES6+):** Dynamic navbar scroll behavior, mobile navigation drawer toggle, and test drive form submission handling.
- **Font Awesome 6:** Vector icon integration.
- **Google Fonts:** `Inter` and `Oswald` typography.
